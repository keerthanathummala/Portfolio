04 · Projects
Flagship OrbitOps Assistant
⌄
A full-stack, locally hosted AI web app that merges a RAG document Q&A system and a multi-tool LangGraph agent into one chat interface. Built end to end with zero paid resources.
Python · FastAPI · LangGraph · LangChain · ChromaDB · BM25 · Sentence-Transformers · Ollama · React · Vite
What it does
  • Document Q&A (RAG): Upload PDF, DOCX, TXT or MD files and ask questions in plain language. Hybrid retrieval combines BM25 keyword search with dense vector search (ChromaDB) via Reciprocal Rank Fusion. A local LLM (Ollama, qwen2.5) writes a cited, grounded answer, and says so when the document doesn't contain one. Benchmarked 4 retrieval methods using Precision, Recall, Hit Rate and MRR.
  • Live research agent: For open-ended questions, a LangGraph decision graph calls GitHub and Hacker News APIs in parallel and combines the results into a structured answer.
Engineering highlights
  • Guardrails: Prompt-injection detection, empty-input blocking, and a faithfulness check that verifies answers against the retrieved source text.
  • Automated evaluation: A 10+ test-case suite scored by a second LLM acting as judge, used to catch regressions during development.
  • Persistence: SQLite-backed chat history and citations that survive across sessions.
Nutrient Profile Classification ⌄
An end-to-end machine learning project in Python. Turns a messy nutrition dataset into engineered features and compares two classifiers, and shows how a misleadingly high accuracy score can hide a flaw.
Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · PCA
What it does
  • Data preparation: Cleaned a 1,590-item, 272-column nutrition dataset into an analysis-ready format. Explored it with Pandas, Matplotlib and Seaborn, and used PCA to see how the features group.
  • Classification: Engineered ratio features (protein-per-calorie and sodium-to-potassium) and compared K-Nearest Neighbours and Random Forest classifiers to predict the nutrient-profile class label.
Engineering highlights
  • Leakage detection: Evaluation showed data leakage inflating the accuracy. Traced the cause and proposed a corrected feature set for a more honest estimate of performance.
  • Model comparison: Compared a distance-based model (KNN) against an ensemble model (Random Forest) on the same prepared data.
Resume Tracker Extension ⌄
A browser extension for job seekers to manage their application pipeline without leaving the browser, built with React.js on the frontend and a Java backend, using JSON for data persistence.
React.js · Java · JSON · HTML/CSS
What it does
  • Account & auth: Secure user registration and login, so each user's application history is private and tied to their own account.
  • Job-application tracking: A dynamic dashboard for logging applications (company, role, status, dates) and updating them as they move through the pipeline (applied → interview → offer/rejected), giving a single place to track an otherwise scattered job search.
  • Session persistence: User data is saved and reloaded via JSON, so application history survives across browser sessions without needing a full database.
Engineering highlights
  • AI-assisted development: Used AI coding tools (Claude Code, GitHub Copilot) throughout to accelerate feature development and debugging, a deliberate choice to work faster without sacrificing code quality.
  • Extension architecture: Built as a browser extension rather than a standalone web app, meaning it had to work within the constraints of extension permissions, storage, and lifecycle (popup/background scripts) rather than a conventional client-server setup.
  • Full-stack scope: Despite being a smaller project, it spans the full stack (React UI, Java-based logic, JSON data layer), giving practical reps across the same layers used in the larger projects.
